# Projeto OOP - FIAP
Repositório didático para estudo de programação orientada à objetos (do inglês *OOP*).

# Objeto selecionado
Para essa atividade, foi escolhido uma **garrafa** como objeto

## Como usar
A classe conta com atributos como tamanho, capacidade, líquido e se está aberta. Além disso, possui um método para abri-la ou fecha-la, também como para beber. Os dois métodos iniciais alteram o estado da variável booleana, enquanto o final apenas exibe uma mensagem no terminal baseada no estado da garrafa.
